# ──────────────────────────────────────────────────────────────────
# IMPORTANT — safer-config notes for the pick-drop runs below
# ──────────────────────────────────────────────────────────────────
# Symptoms observed on a 1-demo run: gripper closes then immediately
# opens; second episode grabs object and trips a reflex abort with
# joint_velocity_violation. Root causes:
#
#  (1) Demos recorded at 10 Hz (demo-hz default) but control loop ran
#      at 15 Hz (control-hz default). The delta-joint actions in the
#      demo were sized for a 10 Hz step; replayed at 15 Hz they are
#      1.5x too fast.  →  match rates: --control-hz 10
#
#  (2) --joint-delta-clip default 0.25 rad/step × 15 Hz = 3.75 rad/s,
#      which exceeds Franka joint velocity limits (~2.17 rad/s on
#      joints 1-4). Drop to 0.05  →  0.5 rad/s at 10 Hz. Safe.
#
#  (3) ARSQ.act samples stochastically during training; with only 1
#      demo the critic has almost no signal, so the gripper dim
#      (threshold >0.5) flips on sampling variance.  →  record 3-5
#      waypoint demos (still PoC-scale) and heavily weight BC via
#      --demo-batch-size 256 --batch-size 32.
#
# Also: --velocity-factor 0.15 keeps the *commanded* dynamics slow
# so the reflex has more margin before firing.
# ──────────────────────────────────────────────────────────────────


# ── RUN A: ARSQ-base (no physics) on pick-drop ──

    --no-fk-reg \
